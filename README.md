## What was styled in this lab
Styled the course catalog utilizing Tailwind CSS and shadcn/ui. The application has been fully redesigned with a custom medieval fantasy theme, preserving shadcn/ui functionality while using complex aesthetic classes. Implemented a responsive grid (up to 4 columns on xl displays) for the course list, a styled navigation bar with hover effects, and a custom `medieval` style variant for the shadcn Button component. Dark mode is also supported natively using the `dark:` prefix.

## Launch Instructions

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
